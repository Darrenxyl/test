# Figma UI 设计提示词

## 设计目标

为“检测仪器行业多专家智能体网站”生成一期前端 UI 设计稿。产品主要服务公司内部销售和售前，整体风格参考豆包的智能体页面结构，但必须更偏向内部业务工具，不要娱乐化、不要泛 AI 玩具感。

## 产品背景

- 这是一个检测仪器行业的多专家智能体网站
- 一期核心用户是销售和售前
- 用户不是统一入口自动分流，而是先选择专家，再进入对应专家聊天页
- 一期首批专家共 5 个
  - 通用检测专家
  - 尺寸检测行业专家
  - 材料力学性能检测行业专家
  - 硬度计专家
  - 闪测仪专家

## 设计范围

请优先生成两张核心页面：

1. 专家选择页
2. 专家聊天页

## 视觉方向

整体视觉要体现“工业、专业、克制、可信赖”。

- 不是娱乐产品
- 不是通用聊天机器人
- 不是紫色互联网风
- 不要花哨动效
- 不要过度拟物
- 不要复杂插画

建议采用：

- 浅色背景
- 深蓝或青绿色主色
- 少量橙色或黄色强调色
- 高可读性的中文无衬线字体
- 大量留白
- 卡片化信息层级

气质关键词：

- 专业
- 清晰
- 工具感
- 高效
- 稳重

## 页面 1：专家选择页

### 页面目标

让用户快速找到合适专家，并明确每个专家的职责边界。

### 页面结构建议

- 左侧导航栏
- 顶部搜索区
- 中间分类切换区
- 专家卡片列表区
- 最近使用区
- 推荐专家区

### 左侧导航栏

保留以下入口：

- 新对话
- 专家广场
- 历史会话

后续可预留：

- 我的收藏
- 最近使用

### 顶部搜索区

支持按专家名称或问题关键词搜索。

搜索框占位文案建议：

- 搜索专家名称或问题关键词，如“硬度计”“闪测仪”“尺寸检测”

### 分类切换区

分类固定为：

- 通用专家
- 行业专家
- 设备专家

### 专家卡片

每张卡片必须清楚说明：

- 专家名称
- 一句话定位
- 可解决的问题
- 支持的输入类型
- 进入对话按钮

卡片文案建议方向：

- 通用检测专家：需求初判、方向梳理、问题归类
- 尺寸检测行业专家：尺寸检测方案、技术路线、设备方向
- 材料力学性能检测行业专家：检测方法、流程、设备方向
- 硬度计专家：选型、方法说明、适用性判断
- 闪测仪专家：判单、型号推荐、测量方式建议

### 推荐专家区

优先突出最常用、最有业务价值的专家。

推荐顺序建议：

- 闪测仪专家
- 硬度计专家
- 通用检测专家

### 交互要求

- 点击卡片直接进入对应专家聊天页
- 卡片 hover 要有清晰但克制的反馈
- 分类切换要明确，不要复杂动画
- 搜索结果要即时可见

## 页面 2：专家聊天页

### 页面目标

让用户与指定专家进行独立咨询，并快速获得结构化、可复用的结果。

### 页面结构建议

- 顶部栏
- 专家定位说明区
- 主聊天区
- 输入区
- 示例问题区
- 右侧辅助说明区

### 顶部栏

应显示：

- 专家名称
- 专家定位
- 边界说明
- 切换专家入口

### 专家定位说明区

进入页面后要让用户立刻知道这个专家能做什么。

示例文案：

- 我是闪测仪专家
- 你可以向我咨询闪测仪相关问题，也可以上传图纸或文档，我会协助判断方向并提供建议

### 主聊天区

聊天气泡要简洁、专业、信息密度高。

### 输入区

支持：

- 文本输入
- 文件上传
- 发送按钮

输入框占位文案建议：

- 请输入你的问题，或上传图纸 / 文档让我辅助判断

### 示例问题区

建议放 3 到 5 个快速提问按钮，降低首次使用门槛。

示例：

- 这张图纸能不能用闪测仪测量？
- 推荐一款适合当前工件的闪测仪型号
- 这个样品适合使用哪种硬度计？

### 右侧辅助说明区

建议展示：

- 我能帮你做什么
- 你需要提供什么信息
- 支持上传哪些资料
- 回答会输出哪些内容

## 回答展示规范

行业专家和设备专家的回答尽量采用结构化模块，不要纯散文。

建议模块：

- 结论
- 推荐设备或推荐方向
- 推荐理由
- 缺失信息
- 风险与限制
- 下一步建议

其中设备专家要更强调：

- 能不能做
- 推荐哪款
- 为什么推荐
- 需要满足什么条件

## 设计注意事项

- 不要让页面像社交平台
- 不要像消费级 AI 产品
- 不要让卡片内容过空
- 不要把按钮做得太娱乐化
- 不要用过多装饰性图形
- 保持业务工具的可信感和高效感

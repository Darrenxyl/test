# AI-agent-web

This repository contains AI-related project materials.

## Main areas

- `requirements/`: product and MVP requirement documents
- `skills/`: reusable skills and references
- `talkings/`: session notes and discussion outputs
- `GEO/`: GEO-related subproject materials and plans

## Version Control Workflow

This project follows a standard Git workflow to manage changes locally and remotely.

### Branching Strategy

- `main`: The stable production branch.
- `develop`: The active development branch (optional, depending on team size).
- `feature/*`: Branches for developing new features.
- `bugfix/*` / `hotfix/*`: Branches for fixing bugs.
